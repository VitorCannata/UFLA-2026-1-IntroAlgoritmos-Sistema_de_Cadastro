# UFLA-2026-1-Introdução_aos_Algoritmos-Sistema_de_Cadastro
Nomes: Nycollas Richard Pereira dos Santos, Luís Fellipe Dias Teodoro, Vitor Cannata de Carvalho

O código em C++ deste repositório consiste em ler jogos de um arquivo .csv (identificador, ano de lançamento, nome, plataforma e descrição), alocá-los em um vetor alocado dinamicamente e realizar diferentes funções, como pesquisar, ordenar, adicionar, deletar jogos e salvar alterações feitas pelo usuário (todas divididas em diferentes subprogramas).
Para um relatório completo, abrir o arquivo PDF presente no repositório.
